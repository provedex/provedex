# Apps

Deployable end-user applications. Distinct from `crates/` (libraries and reusable services) and `bindings/` (FFI wrappers).

## Current

- `demo-web/` - vanilla HTML/JS/CSS single-page UI for the live voice scribe demo. Served statically by `crates/provedex-server/` on port 3000.

## Planned

- `dashboard-web/` - operator dashboard for the hosted aggregator.
- `regulator-portal/` - read-only audit portal regulators can be invited to.
