# Compliance mappings

How Provedex events satisfy specific regulator clauses.

Planned:

- `eu-ai-act.md` - Article 12 logging obligations, Article 13 transparency, Annex IV technical documentation.
- `hipaa.md` - 45 CFR Part 164 audit log requirements, Security Rule mappings.
- `finra-recordkeeping.md` - FINRA 4511, SEC 17a-4 retention rules for voice and AI-mediated communications.
- `nist-ai-rmf.md` - NIST AI 100-1 measurement and management mappings.
- `pci-dss.md` - PCI-DSS audit-trail requirements where AI agents handle cardholder data.

Each doc lists: the clause text, what Provedex emits for it, what is still on the customer to do.
